Jellyfin

Connect Jellyfin to automatically track your watching progress.

Webhook Events

Play and Stop events are always processed. Enable these to sync manual watched changes from the unofficial Webhooks plugin.

Process MarkPlayed events

Mark media as watched when it is manually marked played in Jellyfin.

Process MarkUnplayed events

Remove watched progress when it is manually marked unplayed in Jellyfin. This event can delete media from Yamtrack.
